# Instant Capture Mode Prototype

A gesture-driven instant photo capture system inspired by smart glasses
(Meta Ray-Ban–style devices), focused on minimizing time-to-first-shot.

## Features
- Mode-based capture (IDLE / INSTANT_CAPTURE)
- Gesture abstraction (tap, long-press)
- Camera abstraction layer
- Cold vs warm capture timing
- Burst detection
- CSV telemetry export

## Tech
- Kotlin (JVM)
- Termux (mobile-only development)
- Simulated camera backend

## Goal
Explore low-latency camera interactions for wearable photography without
owning the hardware.
